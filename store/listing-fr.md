## Nom de l’application

Anchor Point

## Description courte (≤ 255 caractères)

Alarme d’ancrage GPS sur la montre. Fixez un point et un rayon ; alerte son/vibration si le bateau sort du cercle. Gardez l’app ouverte pendant la surveillance.

## Description longue

Anchor Point compare la position GPS de votre bateau à un point d’ancrage fixé sur la montre. Si vous sortez du rayon choisi, la montre vous alerte.

Utilisation :

1. Ouvrir Anchor Point (liste d’apps ou glance).
2. Attendre que la montre affiche **GPS bon**.
3. Régler le rayon avec UP/DOWN (15–50 m par pas de 5 m, ou 75 / 100 m).
4. Appuyer sur START pour fixer l’ancre et démarrer la surveillance.
5. Laisser l’app ouverte. La montre affiche la distance et le statut DEDANS/DEHORS.
6. En cas de dérive : son et/ou vibration. START = silence 60 secondes, UP/DOWN = changer le rayon, MENU = arrêter ou continuer.
7. Pour terminer, ouvrir le menu et choisir **Arrêter la surveillance**.

Gardez l’app au premier plan tout le temps — la fermer arrête la surveillance. Pour le son, réglez les **Tonalités d’alerte** de la montre sur **Activé** (pas seulement « Pendant l’activité »).

Ceci est une aide de conscience secondaire. Le GPS peut varier ; ne vous y fiez pas comme seul système de sécurité.

Pas d’app téléphone, pas d’alertes à distance, pas de cartes, pas d’enregistrement FIT, pas de surveillance en arrière-plan une fois fermée.
