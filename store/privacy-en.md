# Privacy statement — Anchor Point

Use this (or host it as a short page and link it from the store listing).
This is a draft for the current MVP; it is not legal advice.

## Summary

Anchor Point uses GPS on your Garmin watch to measure distance from an anchor point you set. Location is processed **on the device** for that purpose. This version does **not** send location or personal data to a developer server over the internet.

## Data used

| Data | Purpose | Where |
|------|---------|--------|
| GPS position | Set anchor, compute distance, trigger alarm | On watch only during the session |
| App settings (default radius) | Remember radius preference | Device app properties / Garmin Connect settings sync as provided by Garmin |
| Optional FIT activity | Save a boating session to your activity history | Watch storage; may sync via Garmin Connect like other activities |

## What we do not do (MVP)

- No companion app messaging
- No cloud backend operated by the app developer
- No advertising identifiers
- No sale of personal data

## Permissions

- **Positioning** — required for the geofence
- **Fit** — optional activity recording when you start a session

## Your choices

- Do not start a session if you do not want GPS used.
- Discard the session instead of saving if you do not want a FIT file.
- Uninstall the app to remove it from the device.
