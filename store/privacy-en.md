# Privacy statement — Anchor Point

Use this (or host it as a short page and link it from the store listing).
This is a draft for the current MVP; it is not legal advice.

## Summary

Anchor Point uses GPS on your Garmin watch to measure distance from an anchor point you set. Location is processed **on the device** for that purpose. This version does **not** send location or personal data to a developer server over the internet, and it does **not** record a FIT activity file.

## Data used

| Data | Purpose | Where |
|------|---------|--------|
| GPS position | Set anchor, compute distance, trigger alarm | On watch only during the session |
| App settings (default radius, alarm style) | Remember preferences | Device app properties / Garmin Connect settings sync as provided by Garmin |

## What we do not do (MVP)

- No FIT / activity recording
- No companion app messaging
- No cloud backend operated by the app developer
- No advertising identifiers
- No sale of personal data

## Permissions

- **Positioning** — required for the geofence

## Your choices

- Do not start a session if you do not want GPS used.
- Uninstall the app to remove it from the device.
